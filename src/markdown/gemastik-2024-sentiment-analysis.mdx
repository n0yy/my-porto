# 🇮🇩 GEMASTIK 2024: Indonesian Sentiment Analysis with IndoBERT

**🚀 Tags:** IndoBERT, NLP, Sentiment Analysis, Python, GEMASTIK

---

### 🧐 **Overview**
As part of the **GEMASTIK 2024 (Data Mining)** competition, I performed deep sentiment analysis on the **Mobile Bea Cukai** app reviews from the Google Play Store.

---

### 🧠 **Natural Language Processing**
Using **IndoBERT**, a pre-trained model optimized for the Indonesian language, I analyzed thousands of user reviews to understand public perception and common pain points.

- **🔍 Analysis:** Conducted N-gram analysis to identify frequent phrases.
- **💡 Key Finding:** Identified high-frequency critical feedback, such as specific app terminology and common user complaints, providing a roadmap for UI/UX improvements.
- **📈 Methodology:** Leveraged Python and state-of-the-art NLP libraries to ensure high classification accuracy for informal Indonesian text.
